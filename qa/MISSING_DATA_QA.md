# 실제 데이터 연결 검증
- 공식 무인증 원문 200을 별도 연구에서 확인. 보존된 응답으로 KPX 파서 값/시각 및 기상특보 5건, 산불·산사태 빈 목록 schema 검증.
- 로컬 135개 테스트 전부 통과. JS 구문/Worker 빌드/ESM/diff 검사 통과.
- managed fixture 미리보기에서 실제 UI 숫자 표시, 전국 공개목록 상태, 미래 특보 시각 상세·닫기 확인. 320px 모바일 시각 확인. 개발 preview 종료, dev 명령 복구.
- 운영 Worker 경유 검증은 배포 후 root 담당. 실제 기기/알림 발송 검증 아님. 예시 fixture는 배포 Worker에 포함하지 않음.
- 지역뉴스 실제 최소 2건 공급 미완료. MCEE는 국내 주제 다양성 보강용 제목/날짜/링크 소스이며 본문 권리 확인 전 AI 해설 금지.
