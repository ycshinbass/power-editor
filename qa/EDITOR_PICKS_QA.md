# 에디터 픽·뉴스 구성 변경 검증 — 2026-11-01

- ‘선정 이유’를 ‘에디터 픽’으로 변경. 기존 원문 검토 메모 6건을 사실 의미를 유지한 짧은 문장으로 편집. 기존 중앙 저장본에도 표시 단계의 선정과정 문장 제거와 길이 제한 적용.
- 처음 5건 표시. 같은 주제는 뒤로 배치하고 제목이 거의 같은 중복을 억제. 저장 목록은 보존. 더 보기에서 추가 열람 가능.
- 관심지역 설정은 신선한 관련 지역자료 최소 2건을 우선 확보하되 2건 상한이 아님. 중요 지역기사 3건 이상도 포함 가능. 전국 설정은 지역할당 없음. 오래된 배경기사를 신규 지역기사처럼 채우지 않음.
- 지역자료 부족 시 첫 화면에 부족 안내. 현재 피드가 실제 지역 2건을 제공한다고 보장하지 않음. 신규 지역 수집원은 미연결.
- 127개 테스트 통과: 주제 다양성, 유사제목 중복, 지역 최소값/3건 이상, 전국 예외, 자료 부족, 기존 편집문 표시 등을 확인.
- JS 구문, Worker 조립·빌드·ESM, diff 공백 검사 통과.
- 로컬 fixture 브라우저: 처음 5건, 에디터 픽, 전국 설정 후 할당 안내 숨김 확인. 320px 뉴스 문체·레이아웃 시각 확인. 실제 운영 API/푸시 호출 없음.
- Preview 정지, dev 명령 복구. 배포는 root 담당.
- 공식 지역 보도자료 신규 수집 가능성 조사: 직접 무인증 목록 요청 HTTP 503, 상세자료 2건 및 자동 수집/항목별 재사용 조건 미검증. 다른 경로로 제한을 우회하지 않음.
