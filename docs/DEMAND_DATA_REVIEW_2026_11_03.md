# 전력 수요 데이터 배치 검토 — 2026-11-03

이번 변경은 `?news-preview=naver#power-data-preview` 검토용 화면에만 적용한다. 실제 수요예측 수집, 모델 실행, API 신청, 운영 스케줄 변경은 하지 않는다. 기존 전국 수급과 발전원 수집은 유지한다. 신규 수요·비교값은 가상 예시라고 표시한다.

## 결론

KPX가 발표한 예측 **결과**를 활용하고, 피크·같은 시간 비교·실적 대비 차이를 프로그램으로 계산하는 방식을 우선 추천한다. KPX 운영 모델의 실행 코드·학습값·재배포 라이선스는 이번 공식자료 확인에서 확보하지 못했다. 공개 연구보고서를 읽을 수 있다는 사실이 운영 모델 복제 권한을 뜻하지 않는다. 독자 모델을 개발한다면 별도 모델로 명명하고 시계열 분리 검증과 오차 평가를 거친다.

## 화면 순서

1. 지역 현재날씨는 기존 페이지 최상단 날짜 옆을 유지한다. 수요 아래의 중복 날씨 블록은 제거했다.
2. 수급 요약은 두 칸: 실제 공급예비율을 크게, 현재수요·공급예비력은 작은 보조 수치로 묶는다. 옆에 같은 시간 대비 **수요** 증감을 강조한다. 증감은 가상 예시 표시를 붙이며 예비율 변화(%p)와 혼동하지 않게 한다.
3. 오늘의 수요 전망: 예측 최대·피크 시간은 한 줄로 압축하고 실적·예측·비교 기준 그래프를 유지한다. 평소/어제 전환과 시간 탐색을 제공한다.
4. 발전원 구성: 기존 누적 그래프를 기본 화면에 펼쳐 표시한다. 범례는 작게, 세부 수치는 접힌 상세 영역으로 옮긴다. 실제 발전출력과 가상 수요 전망을 겹치지 않는다.
5. 우리지역 확인사항, 카테고리 뉴스, 일정 순서는 유지한다.

추가 색상 요청: 채도 높은 빨강·파랑을 중심으로 시안 팔레트를 변경했다. 공급예비율은 파란 면과 흰 숫자, 수요 증감은 옅은 붉은 면과 빨간 숫자, 실제 수요는 파란 실선·예측은 빨간 점선으로 구분한다. 발전원별 범례 색상은 유지한다. 공식 위기 단계는 색에서 추정하지 않으며, 한전 공식 로고/서비스 표시를 추가하지 않는다. 개인 제작 표시를 유지한다.

## 요약바와 지역 현황 후속 수정

- 번호 붙은 섹션 부제, ‘수요를 미리 읽는 하루’, 안내성 제목·중복 설명을 제거한다. 자료 시각·단위·예시 구분·미확인 상태는 유지한다.
- 지역 영역 제목은 ‘우리지역 대기질·특보·재난’. 산불·산사태·국내 지진은 하나의 카드에 묶고 각각 상세 버튼을 유지한다.
- 0건·미확인·대기 상태는 공통 중립 색상. 확인된 현재 발생/발효만 강조한다. 자료 실패·지역 매칭 실패를 0건으로 바꾸지 않는다. 일부 판별이 불가능해도 확인된 발효 항목은 보여준다.
- 지진은 최근 24시간에 발생한 것으로 확인된 국내 발표만 표시한다. 해외·미래·24시간 초과·시각 미확인·이전 자료는 현재 강조에서 제외한다. 전체 지진 목록이나 관심지역 피해를 의미하지 않으며, 이 필터는 시안과 시안 상세창에만 적용한다.
- 화면 상단 sticky 요약바에 기존 관심지역 버튼과 현재날씨 버튼, 실제 공급예비율, 작은 **가상 수요 그래프**, **예시 한전 헤드라인**, 작은 정전 보도 버튼을 배치한다. 신규 수집·본문 요약·AI 호출 없음.
- 발효/발생이 확인되면 요약바에 상세보기 버튼을 표시한다. 확인된 항목이 없고 자료가 모두 정상일 때에는 재난 행을 숨긴다. 미확인은 작은 중립 안내로 표시하고 정상/안전으로 단정하지 않는다.
- 기존 상단 현재날씨의 위치를 유지하면서 스크롤에도 보이도록 요약바로 이동한다. 날짜는 바로 아래 첫 화면에 유지한다. 정전 기사 버튼은 기존 기사 상세창을 열며, 보도 수를 실제 정전 수로 표현하지 않는다.
- 검증: 표시 규칙 단위 테스트에 활성/0건/미확인/발효예정/부분 판별 및 국내·해외·과거·미래 지진을 포함한다. 모바일·스크롤·상세보기 동작은 게시된 검토용 URL에서 확인한다.

현재 수급은 5분 순시자료, 신규 비교 그래프는 1시간 평균 가정으로 구분한다. 실제 연동 전에 육지/제주/전국, 전력시장/총수요, 발전단/송전단, 시간 간격과 계량 범위가 일치하는지 확인한다. 맞지 않으면 두 데이터를 뺀 ‘예측 오차’를 노출하지 않는다. 발전원 합계를 임의로 수요 실적으로 대체하지 않는다. 예비율로 지역 계통 안전 또는 공식 위기단계를 추정하지 않는다.

## 후속 연동 조건

- 공식 예측을 서버에서 공유 캐시한다. 매 조회·지역 전환마다 재요청하지 않는다. 공식 발표 주기에 맞춰 하루 1회+제한된 재시도, 승인 한도보다 낮은 상한을 둔다. 현재 예약 작업은 변경하지 않았다.
- 대상일·발표시각·수집시각·지역 범위·수요 정의·단위를 보존한다. 하루전 예측을 실시간 재예측처럼 표시하지 않는다.
- 평균 비교는 같은 요일·같은 시간, 공휴일/결측을 제외한다. 표본 부족이면 미표시. 전주 대비/평소 대비는 날씨 보정 효과가 아니다.
- 예측 오차는 동일 범위의 완결된 시간 평균 실적이 있을 때만 계산한다. 미래 실적·결측을 0으로 채우지 않는다.
- 지역 기상 기반 독자 모델은 해당 지역의 수년간 시간별 부하와 기상·휴일·산업 구조 등이 확보된 뒤 검토한다. 무작위 분할 대신 미래 기간을 분리한 검증, 단순 기준모델 대비 개선과 오차 범위를 확인한다. 현재는 구현하지 않았다.
- 수치 계산·그래프·캐시는 LLM 호출 없이 가능하다. 서버/API 비용까지 0이라고 보장하지 않는다.
- SMP, 독자 위험점수, 검증 전 기상 민감도 계수는 첫 화면에서 제외하는 안이다. 바쁜 현업 독자의 수요·피크·변화 파악에 집중한다.

## 지역별 표시 제안 — 아직 연동하지 않음

- 우선안은 ‘우리지역 전력사용 추이’: 한전 시군구 월간 판매량의 최신 공개월, 전년 동월 대비, 최근 12개월 소형 그래프. 월간 통계를 현재 MW나 당일 수요로 표현하지 않는다.
- 지역 공급 쪽은 KPX 지역 발전·거래 통계를 별도 정의로 표시한다. 시도별 태양광 자료와 육지/제주 풍력 자료는 지역 범위가 다르다. 전력시장 미참여·자가용 등 누락 범위를 명시한다. 지역 발전량은 해당 지역 소비자에게 공급된 총량이 아니며, 발전량만으로 지역 공급예비율을 계산하지 않는다.
- KPX 지역별 시간별 계량자료(https://www.data.go.kr/data/15122362/fileData.do)는 2013–2025년 광역시도 자료 후보이다. 계량 대상의 정의와 갱신 방식 확인 전에는 지역 소비 부하나 실시간 피드로 채택하지 않는다.
- 지역별 오늘·내일 공식 예측의 공개 자동수집 경로는 확보하지 못했다. KPX·한전 공식 분석/예측을 최우선으로 표시하며, 전국 전망을 시군구 전망으로 바꾸지 않는다.
- 지역 시간별 소비 부하가 확보되면 기상·요일·휴일과 결합한 독자 추정 후보를 검토한다. 공개 공식 결과와 분리하고 과거 기간 외 검증을 통과한 경우에만 오차 범위와 함께 제공한다.
- 이번 레이아웃 변경은 신규 API/AI 호출을 추가하지 않는다. 지역 데이터 검토 결과는 제안이며 수집·예측·정확도 검증 완료를 뜻하지 않는다.


## 모바일 시안 정리 — 2026-11-03

- 발전출력은 검증된 원자료 MW를 표시 단계에서 GW로 변환한다. 원자료·음수 양수·결측 처리·전일 비교는 보존한다. 표시 수치는 소수점 한 자리이며 차트 내부 계산은 원래 정밀도를 유지한다.
